克隆样本（仅支持 mp3 / wav，Base64 编码后不超过 10 MB）

录音会自动转码为 16kHz 单声道 WAV；上传的 mp3 / wav 原样发送。若 Base64 超过 10 MB，可点「转码压缩」；压缩后仍超限时请截取约 4 分钟以内的片段。浏览器录音得到的是 webm，本页会先转成 wav 再生成 Data URL。

接口要点

    
    
      
  • MiMo TTS 复用 OpenAI 兼容的 Chat Completions 接口：POST {MIMO_API_BASE_URL}/chat/completions，请求头使用 api-key（不要用 Authorization: Bearer，Token Plan 的 tp- 开头 Key 在部分环境下用 Bearer 会 401）。
    • 
      
  • 待合成正文必须放在 assistant 消息；user 消息只放风格指令或音色描述。正文放在 user 里会报 messages must contain an assistant role for TTS model。
    • 
      
  • audio.format 支持 wav / mp3 / pcm / pcm16；不支持 opus 与 aac。pcm16 用于流式拼接。
    • 
      
  • voiceclone 与 voicedesign 的低延迟流式尚未真正上线（流式调用会降级为全部生成完后一次返回），本页统一走非流式调用。
    • 
    

  

  

    
本地与安全

    
    
      
  • API Key 只保存在服务端 .env，浏览器端代码与网络请求中均不出现密钥；修改 .env 后需重启 node server.js。
    • 
      
  • 相同 payload（SHA-256）命中本地缓存 .cache/tts/，不再调用 MiMo API、不重复消耗额度；清空缓存可直接删除该目录。
    • 
      
  • 健康检查 GET /api/health；代理入口 POST /api/tts（仅同源本地调用）。
